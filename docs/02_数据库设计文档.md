## 2. 表结构

### 2.1 users - 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | Integer | PK, AUTO_INCREMENT | 用户ID |
| username | String(50) | UNIQUE, NOT NULL | 用户名 |
| hashed_password | String(200) | NOT NULL | bcrypt加密密码 |
| is_active | Boolean | DEFAULT True | 是否激活 |
| created_at | DateTime | DEFAULT now() | 创建时间 |

```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    hashed_password VARCHAR(200) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

---

### 2.2 tables - 牌桌表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | Integer | PK, AUTO_INCREMENT | 牌桌ID |
| user_id | Integer | FK → users.id | 所属用户 |
| my_position | String(10) | NOT NULL | 我的位置: BTN/SB/BB/UTG/MP/CO |
| num_players | Integer | NOT NULL | 玩家总数(2-6) |
| my_hole_cards | String(20) | | 初始手牌，如 "As Kh" |
| buy_in | Numeric(10,2) | NOT NULL | 买入筹码 |
| small_blind | Numeric(10,2) | DEFAULT 5 | 小盲 |
| big_blind | Numeric(10,2) | DEFAULT 10 | 大盲 |
| my_stack | Numeric(10,2) | | 我的当前筹码 |
| pot_size | Numeric(10,2) | DEFAULT 0 | 当前底池 |
| community_cards | String(50) | | 公共牌，如 "Ks 7h 2d 5c" |
| status | String(20) | DEFAULT "waiting" | 状态: waiting/preflop/flop/turn/river/settled |
| created_at | DateTime | DEFAULT now() | 创建时间 |
| updated_at | DateTime | | 更新时间 |

```sql
CREATE TABLE tables (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    my_position VARCHAR(10) NOT NULL,
    num_players INT NOT NULL,
    my_hole_cards VARCHAR(20),
    buy_in NUMERIC(10,2) NOT NULL,
    small_blind NUMERIC(10,2) DEFAULT 5,
    big_blind NUMERIC(10,2) DEFAULT 10,
    my_stack NUMERIC(10,2),
    pot_size NUMERIC(10,2) DEFAULT 0,
    community_cards VARCHAR(50),
    status VARCHAR(20) DEFAULT 'waiting',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.3 actions - 操作记录表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | Integer | PK, AUTO_INCREMENT | 记录ID |
| table_id | Integer | FK → tables.id | 关联牌桌 |
| stage | String(20) | NOT NULL | 阶段: preflop/flop/turn/river |
| position | String(10) | NOT NULL | 位置 |
| action | String(20) | NOT NULL | 动作: fold/check/call/raise/all-in/agent_analysis |
| action_type | String(20) | NOT NULL | 类型: user_decision / agent_analysis |
| amount | Numeric(10,2) | DEFAULT 0 | 下注金额 |
| pot_after | Numeric(10,2) | | 操作后底池 |
| community_cards | String(50) | | 操作时公共牌 |
| agent_suggestion | String(20) | | Agent建议动作 |
| agent_win_rate | Numeric(5,1) | | Agent计算的胜率 |
| agent_reasoning | Text | | Agent分析理由 |
| created_at | DateTime | DEFAULT now() | 记录时间 |

```sql
CREATE TABLE actions (
    id INT AUTO_INCREMENT PRIMARY KEY,
    table_id INT NOT NULL,
    stage VARCHAR(20) NOT NULL,
    position VARCHAR(10) NOT NULL,
    action VARCHAR(20) NOT NULL,
    action_type VARCHAR(20) NOT NULL,
    amount NUMERIC(10,2) DEFAULT 0,
    pot_after NUMERIC(10,2),
    community_cards VARCHAR(50),
    agent_suggestion VARCHAR(20),
    agent_win_rate NUMERIC(5,1),
    agent_reasoning TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (table_id) REFERENCES tables(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.4 opponent_profiles - 对手画像表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | Integer | PK, AUTO_INCREMENT | 画像ID |
| user_id | Integer | FK → users.id | 所属用户 |
| opponent_name | String(50) | NOT NULL | 对手位置标识: UTG/MP/CO等 |
| vpip | Numeric(5,2) | DEFAULT 0 | 自愿入池率(Voluntarily Put In Pot) |
| pfr | Numeric(5,2) | DEFAULT 0 | 翻前加注率(Preflop Raise) |
| aggression | Numeric(5,2) | DEFAULT 0 | 攻击指数 |
| style | String(20) | DEFAULT "unknown" | 打法风格: tight_passive/loose_passive/tight_aggressive/loose_aggressive/unknown |
| total_hands | Integer | DEFAULT 0 | 对战手数 |
| created_at | DateTime | DEFAULT now() | 创建时间 |
| updated_at | DateTime | | 更新时间 |

**唯一约束**: (user_id, opponent_name)

```sql
CREATE TABLE opponent_profiles (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    opponent_name VARCHAR(50) NOT NULL,
    vpip NUMERIC(5,2) DEFAULT 0,
    pfr NUMERIC(5,2) DEFAULT 0,
    aggression NUMERIC(5,2) DEFAULT 0,
    style VARCHAR(20) DEFAULT 'unknown',
    total_hands INT DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    UNIQUE KEY uk_user_opponent (user_id, opponent_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 3. ER关系图

```
users (1) ──→ (N) tables        一个用户可以创建多个牌桌
users (1) ──→ (N) actions       一个用户可以有多条操作记录(间接通过table)
users (1) ──→ (N) opponent_profiles   一个用户可以有多个对手画像
users (1) ──→ (1) user_poker_profiles  一个用户一个扑克画像
tables (1) ──→ (N) actions      一个牌桌有多条操作记录
```

---

## 4. 数据流

```
创建牌桌 → tables.insert
  ↓
每轮行动 → actions.insert (agent_analysis / user_decision)
  ↓
Agent分析 → 读取 opponent_profiles + user_poker_profiles
  ↓
结算 → tables.update(status=settled) + 更新 user_poker_profiles
  ↓
对手画像更新 → opponent_profiles.upsert (根据行动统计vpip/pfr/aggression)
```

## 7. 关键约束与注意事项

1. **Numeric精度**: 金额字段统一用 `Numeric(10,2)`，不用 Decimal 类型（SQLAlchemy兼容问题）
2. **datetime.now()**: ORM默认值必须写 `datetime.now` 带括号，否则所有记录同时间
3. **UniqueConstraint**: 建表时直接SQL加，ALTER可能不生效
4. **异步引擎**: 所有数据库操作用 `AsyncSession`，CRUD函数都是 `async`
5. **连接池**: FastAPI启动时创建引擎，通过 `get_db` 依赖注入session
